# 맥락 파일 채우는 법

이 스킬은 맥락 파일 없이도 돈다(범용). 채우면 달라지는 것은 세 가지다.

| 칸 | 채우면 |
|---|---|
| `brands.ours` · `brands.competitors` | 경로 맵과 검색어 표에 «우리» · «경쟁» 표시가 붙는다(`context_paths.py --context assets/context.json`) |
| `guardrails` | 에이전트가 요약과 실행 카드를 쓸 때 지키는 표현 규칙이 된다 |
| `decision.who_decides` · `internal_metrics` | 실행 카드의 담당 역할과 «함께 볼 내부 데이터»에 쓰인다 |

## 순서

1. `assets/context.starter.json`을 `assets/context.json`으로 복사한다.
2. 빈 칸 표시가 붙은 값을 아래 표대로 바꾼다. 쓸 것이 없는 줄은 지운다 — 빈 칸 표시를 남겨 두지 않는다.
3. `python3 scripts/selftest.py`로 필수 칸이 찼는지 확인한다.

## 칸마다 쓰는 법

| 칸 | 누가 | 쓰는 법 | 예 |
|---|---|---|---|
| `decision.who_decides` | 사람 | 이 리포트로 누가 무엇을 정하는지 한 문장 | "콘텐츠 담당이 다음 달 낼 글 세 편을 정한다" |
| `decision.question_example` | 사람 | 현업에서 받는 질문을 말 그대로 | "이 키워드 검색하는 사람들은 앞뒤로 뭘 찾고 왜 검색해?" |
| `market.gl` | 사람 | 주로 보는 국가 하나. 다른 국가 요청은 실행할 때 묻는다 | `kr` |
| `market.category_boundary` | 그대로 둔다 | 이 스킬의 경계는 «시드와 같은 경로에 나온 검색어까지»다 | — |
| `brands.ours` | 사람 | 검색어에 실제로 쓰이는 표기로. 영문과 한글 표기가 다르면 둘 다 | "헬리녹스", "helinox" |
| `brands.competitors` | 사람 | 5개 이내. 모르면 줄을 지운다 | "콜맨", "스노우피크" |
| `brands.not_brands` | 에이전트 초안 → 사람 확인 | 판매 채널 · 커뮤니티 · 비교 플랫폼 — 브랜드처럼 보이지만 브랜드로 읽지 않을 이름 | "다이소", "쿠팡" |
| `terms` | 에이전트 초안 → 사람 확인 | 같은 뜻으로 묶을 말과 구분해야 하는 쌍 | "릴렉스체어 = 릴랙스체어" |
| `internal_metrics` | 사람 | 지표 **이름**만. 값 · 매출 · 판매량은 적지 않는다 | "상세 페이지 유입 수" |
| `guardrails` | 에이전트 초안 → 사람 확인 | 업종의 표현 규칙 | "효능을 단정하지 않는다" |
| `request_examples` | 그대로 두거나 더한다 | 이 스킬을 켤 요청 예시 | — |

## 지키는 것

- 사람에게 묻는 것은 `who_decides` · 우리 브랜드 · 경쟁 브랜드 세 가지면 된다. 나머지는 에이전트가 초안을 쓰고 확인만 받는다.
- 모른다고 하면 비워 두고 넘어간다. 다시 조르지 않는다.
- 브랜드 표시는 **검색어 안에 그 이름이 들어 있는지**로만 판정한다. 표기가 다르면 걸리지 않으니 실제 검색어 표기를 쓴다.
- 브랜드 표시는 표시일 뿐이다. 이 스킬은 브랜드 점유나 기회 크기를 계산하지 않는다 — 그 질문은 `track-search-share`로 보낸다.
- 내부 지표 값은 어느 파일에도 넣지 않는다.
- 회사 맥락을 채운 스킬 폴더는 공개 저장소에 되돌려 올리지 않는다. 회사 저장소에 따로 둔다.
