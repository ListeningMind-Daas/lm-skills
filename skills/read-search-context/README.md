# read-search-context

시드 키워드 하나를 놓고 **그 검색 앞뒤에 무엇이 붙는지**와 **갈래마다 무엇을 하려는 검색인지**를 답하는 스킬입니다.
ListeningMind DaaS의 `path_finder` · `keyword_info`(검색량 · 월별 검색량) · `serp`를 씁니다. «작년과 비교»는 시드와 앞뒤 갈래의 검색량을 전년 같은 석 달과 견줍니다.

## 무엇이 나오나

| 파일 | 내용 |
|---|---|
| `report.html` | 요약(반대 근거 포함) · 작년 같은 시기와 비교(검색량) · 앞뒤 검색 표와 차트 · 갈래 표 · 대표 경로의 검색 목적(근거 번호 포함) · 실행 카드 · 부록(사실 목록 · 호출 순서 · 비용) |
| `context_map.html` | 시드를 가운데 두고 앞뒤 검색을 눌러 보는 경로 맵 |
| `report.calls.csv` · `report.cost.json` | 호출 로그와 비용 보고서 |
| CSV · JSON | 이음 · 검색어 · 대표 경로 · 근거 원자료 |

## 설치

스킬 폴더를 API 키와 연결이 있는 작업 공간의 스킬 위치에 복사합니다. 파이썬 표준 라이브러리만 씁니다.
처음 실행하면 온보딩(공급원 · 서버 주소 · 키 · 기본값 · 맥락)을 한 번 거칩니다 — `references/onboarding.md`.

## 사용법

"캠핑의자 앞뒤로 뭘 검색해?"처럼 물으면 됩니다. 에이전트가 견적을 보여 주고 경로 수와 크레딧 상한을 확인받은 뒤 진행합니다.
크레딧 없이 흐름만 보려면 합성 자료로 모의 실행합니다(`SKILL.md` 끝의 «모의 실행»).

## 다루는 함정

- **표기변형 이중 계상(T5)** — 띄어쓰기만 다른 검색어를 묶고, 표기만 바뀐 인접은 앞뒤 검색으로 세지 않습니다.
- **절단 오독(T7)** — 받은 경로 수가 요청 수와 같으면 «전체 경로»라고 쓰지 않습니다.
- **경로 수 오독** — 받은 경로는 앞부분을 공유하고 끝만 갈라지는 경우가 있어, 경로 수와 함께 서로 다른 줄기 수를 적습니다.
- **시드 표기 변경** — 응답이 시드를 다른 표기로 돌려주면 멈추고 치환 규칙을 제안합니다.
- **검색량 없음을 0으로** — 값이 없는 검색어는 비워 둡니다.
- **저장된 화면을 지금 화면으로** — 검색 결과 화면 근거마다 수집일을 적습니다.
- **조회일을 데이터 시점으로(T1)** · **덜 찬 최신 달(T2)** · **믿기 어려운 `volume_trend`(T3)** · **작은 기저의 큰 증가율(T4)** · **결측 월을 0으로(T6)** — 작년 비교는 기준월 · 지연을 적고, 최신 달을 뺀 전년비로 교차 확인하고, 석 달 합을 직접 견주고, 게이트 미만은 순위로 쓰지 않고, 결측 월이 있으면 계산하지 않습니다.

## 크레딧

```
총 크레딧 = 1 × 1 + (50 + 40 × U) + 1 × U + 1 × R + 30 × S
```

U는 경로 안 고유 검색어 수, R은 월별 검색량의 반환 행 수(기본 대상 최대 11개 · 표기 변형 행이 더 올 수 있음), S는 검색 결과 화면을 본 검색어 수입니다. U는 호출 전에 알 수 없어 견적은 가정값으로 냅니다.
사용자가 승인한 상한을 넘는 호출은 하지 않습니다.

## 한계

세션 인접 검색의 집계이며 한 사람의 여정이 아닙니다. 구매 · 전환 · 이탈 · 성별 · 연령은 답하지 않고, 작년과의 비교는 검색량만 합니다(지난 시점의 경로는 견주지 않습니다).
검색 결과 화면은 저장본이라 지금 화면과 다를 수 있습니다. 검색 목적은 해석(추정)이며 대안 설명을 함께 둡니다.
