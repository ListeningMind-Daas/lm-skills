# {카테고리} 키워드 유니버스 · 커버리지 리포트

> **데이터 기준월 {YYYY-MM} / 조회일 {YYYY-MM-DD} / 지연 {n}개월** (기준월은 응답에서 읽은 값)
> gl={kr} · 카테고리 경계: {무엇이 안이고 무엇이 밖인지 한 문장}
> 시드 {S}개 · 확장 {k}라운드 · 소진 크레딧 {합계} (`cost_detail.total_cost` 합산)

조회일은 데이터 시점이 아니다. 아래 모든 추세는 **{YYYY-MM} 기준**이다.

## 1. 유니버스 규모

| 지표 | 값 | 라벨 |
|---|---:|---|
| 행 수 (표기변형 포함) | {N} | 실제 데이터 |
| 같은 검색의 중복 행 (`dup_of` — 집계 제외) | {D} | 추정 |
| canonical 그룹 수 | {G} | 추정 |
| 그룹 기준 볼륨 (12개월) — 하한 ~ 상한 | {V_lo} ~ {V_hi} 건 | 추정 |
| 논브랜드 볼륨 비중 — 하한 기준 · 상한 기준 | {p_lo}% · {p_hi}% | 추정 |

그룹 볼륨은 범위다 — 하한은 그룹 내 최댓값(표기변형이 같은 검색의 중복일 때), 상한은 그룹 내
합(서로 다른 검색일 때)이다. 응답만으로는 어느 쪽인지 알 수 없다(계약 T5). 아래 판정 문장은
하한 기준이며, 상한에서 뒤집히는 결론은 따로 적는다.
검색량 단위는 건이며 사람 수가 아니다.

## 2. 커버리지 곡선과 정지 판정

| 라운드 | 입력 | 요청 limit | 반환 | 신규 | 신규 볼륨 | 기여율 | 논브랜드 기여 | 절단 |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| S1·시드 | | | | | | | | |
| R1·확장1 | | | | | | | | |
| R2·확장2 | | | | | | | | |

- 누적 볼륨: 하한 {C_lo} ~ 상한 {C_hi} 건
- **판정: {도달 / 부분 도달 / 보류}** — 근거: 마지막 라운드 기여율 하한 기준 {s_lo}% / 상한 기준 {s_hi}%
  중 큰 쪽 vs 임계 {20}% (두 기준 모두 임계 아래일 때만 «도달»)
- 임계값 {20}%는 `[가정]`이다.
- 절단된 호출이 있는 라운드: {없음 / 라운드명·호출} — 반환 수가 요청 limit에 붙은 호출(시드별로 검사)은 수렴이 아니라
  잘린 것이므로 «도달»로 쓰지 않는다.
- 논브랜드 기여율(하한·상한 중 큰 쪽): {q}% · 논브랜드 공간 하한 {NB_lo} ~ 상한 {NB_hi} 건 — 전체가 수렴해도 이 값이 임계 위면 신규 진입 검토용 지도는
  아직 닫히지 않았다.

## 3. 테마 구성 (행 합 = 상한 기준 볼륨)

| 테마 | 키워드 수 | 볼륨 | 비중 | 논브랜드 비중 |
|---|---:|---:|---:|---:|

분류 미상 비중이 크면 테마 정규식이 부족한 것이다 — 6절 Blind Spot에 적는다.

## 4. 추세 (전년 동기 비교)

비교 창: {최신 3개월} vs {전년 동기 3개월} · 볼륨 게이트: 전년 동기 {3,000}건 이상

| 방향 | 키워드 | 전년 동기 | 현재 | YoY | 마지막 달 플래그 |
|---|---|---:|---:|---:|---|

- API의 `volume_trend`는 판정에 쓰지 않았다. 이번 유니버스에서 직접 계산한 YoY와
  부호 불일치 {r}%. 필드는 CSV에 보존만 했다.
- `last_month_flag`가 붙은 {m}건은 `yoy_ex_last_month`와 교차확인했다.
  방향이 갈린 {m2}건은 **판정 보류**로 남긴다.
- 계절 경고: 3개월 창 YoY는 기준월이 시즌의 어디에 있느냐에 좌우된다.
  {계절성 강/약} 카테고리이므로 `yoy_12m`과 교차확인한 결과 {일치 / 갈림}.

## 5. 점유와 신규 진입 여지

점유율은 검색량 기준 근사이며 `[추정]`이다. 검색은 구매가 아니라 관심 신호다.

| 테마 | 논브랜드 볼륨 | 논브랜드 비중 | 논브랜드 YoY | 평균 CPC | 경쟁도 | 기회 판정 |
|---|---:|---:|---:|---:|---|---|

- 기회 후보 = 논브랜드 볼륨이 크고 · YoY 플러스이고 · 경쟁도가 낮은 테마.
- 브랜드 지배 테마 {테마명}은 볼륨이 커 보이지만 이미 귀속된 수요다.
- 브랜드 사전 점검: 상위 볼륨 논브랜드 키워드 {30}건을 확인했고 브랜드 혼입 {있음/없음}.
  (사전 누락은 논브랜드 공간을 부풀린다.)

## 7. 한계와 크레딧

- 월 그레인 · 약 {n}개월 지연 — 주간 조기경보에 쓸 수 없다.
- 유니버스의 완전함은 증명되지 않는다. 판정한 것은 «더 확장해도 새 볼륨이 거의 안 는다»이지
  «빠진 것이 없다»가 아니다.
- 크레딧 내역 (`cost_detail.total_cost` 합산)

| 단계 | 커넥터 | 계산 | 크레딧 |
|---|---|---|---:|
| 시드 검증 | `keyword_info` `all` | 10 × {S} | |
| 확장 | `intent_finder` | 30 × 입력 + 2 × 반환 | |
| 1단 지표 | `keyword_info` `ads_metrics` | 1 × {N−S} | |
| 2단 추세 | `keyword_info` `all` | 10 × {G−S} | |
