# ListeningMind 데이터 계약 (정본)

> 이 파일은 **정본(canonical)**이다. LM API를 쓰는 모든 스킬이 자기 폴더에 이 파일의
> 복사본을 두고 참조한다. 스킬은 이 계약을 확장할 수 있지만 **뒤집을 수 없다.**
>
> 고칠 때는 정본을 고치고 복사본을 다시 배포한다. 복사본을 직접 고치면 드리프트가 생긴다 —
> `shared/verify_shared.py`가 이를 검사한다.

이 계약이 담는 것은 **커넥터 계약과 데이터 함정**뿐이다. 질문 프레임·잡 라우팅·산출물 형식은
각 스킬의 몫이다.

## 1. 커넥터와 크레딧

크레딧은 **결정식**이다. 관측 범위를 상한처럼 적지 않는다 — 예산이 오도된다.

| 커넥터 | 결정식 | 반환 |
|---|---|---|
| `keyword_info` | `단가 × 키워드` (아래 표) | 볼륨·광고지표 (+옵션) |
| `intent_finder` | `30 × 입력 + 2 × 반환` | **키워드 문자열만** |
| `cluster_finder` | `150 + 고유 키워드(노드) × 50` — 관계 수가 아니다 | 군집·엔티티·관계. `limit`은 **관계 행 수** 상한(노드 수가 아님) |
| `path_finder` | `50 + 경로 내 고유 키워드 × 40` | 세션 인접 경로. `limit`은 **경로 수** 상한 — 과금 단위(고유 키워드)를 묶지 못한다 |
| `serp` | `30 × 키워드` | 검색결과 화면 블록 |
| `trend_finder` | `50 × 결과가 있는 호출 + 2 × 반환 이슈` — 빈 결과 호출은 0 (2026-09-29 개발 환경 실측 1건 · 환경마다 확인) | 시드 주변 급부상 이슈(키워드·이슈 점수·요약·출처). **검색량은 없다** · 빈 결과는 실측(기간을 넓혀 재조회) |
| `cluster_finder/keyword_list` | `30 + 2 × 반환 키워드` — 명세값 · 실측 대조 전 `[가정]` | 관계망 키워드 목록만(군집 구조 없음) · 본 호출 전 규모 확인용 |
| `path_finder/keyword_list` | `30 + 2 × 반환 키워드` — 명세값 · 실측 대조 전 `[가정]` | 경로에 나온 키워드 목록만(경로 순서 없음) |
| `usage/summary` | 명세에 단가 없음 — 조회 전용 · 첫 호출의 `cost_detail`로 확인 | 계정 사용량 집계(개별 분석 소진량으로 쓰지 않는다 — 아래 «크레딧 용어») |

### `keyword_info` data_type — 선택 규칙

| data_type | 크레딧/kw | 반환 |
|---|---:|---|
| `ads_metrics` | **1** | 볼륨·CPC·경쟁도 |
| `ads_info` | **환경마다 다름** (10 · 1 관측) — 쓰지 않는다 | `ads_metrics` + `monthly_volume` |
| `all` | **10** | `ads_metrics` + `monthly_volume` + `features` + `intents` + `demography` |

**핵심 판단**: `ads_info`는 단가가 환경마다 다르게 관측됐고(10 · 1) `all`이 상위집합이다.
→ **이 키트는 `ads_info`를 쓰지 않는다.** 시계열이 필요하면 `all`(10)을 쓴다 — 단가를 환경마다 확인할 필요가 없어진다.

```
스크리닝·볼륨 확보    → ads_metrics (1)   · 유니버스 전량에 걸어도 싸다
시계열·인텐트·인구    → all (10)          · 반드시 선별 대상에만
```

**비용 구조가 여기서 갈린다.** 유니버스 전량에 10크레딧짜리를 걸면 10배가 된다
(332키워드 = 3,320). 시계열이 필요한 것은 **실제로 판정에 쓸 키워드뿐**이므로:

1. 유니버스 전량 → `ads_metrics`로 볼륨 확보 (1/kw)
2. 볼륨 게이트로 **판정 대상만 추림** (예: 전년 동기 볼륨 ≥ 3,000)
3. 추린 것만 → `all` (10/kw)

> ⚠️ 배포 환경마다 단가가 다를 수 있다. 개발 환경에서는 `ads_info`가 1로 청구된 사례가 있다.
> **고객에게 크레딧을 안내하기 전에 해당 환경에서 확인**하고, 위 규칙을 다시 계산한다.

### `keyword_info` 응답과 과금의 대응 (2026-09-28 실측)

- 과금은 **요청한 키워드 수**다. 요청하지 않은 변형 행이 함께 와도 과금되지 않고,
  응답에서 빠진 요청 키워드도 과금된다.
- 응답 키워드는 요청 문자열과 다를 수 있다(`음파칫솔` → `음파 칫솔`). 요청↔응답 대조는
  **canonical로** 한다. 문자열 그대로 대조하면 살아 있는 시드를 죽었다고 판정한다.
- 요청했는데 응답에 없는 키워드는 «결측 0»이 아니라 **미반환 목록**으로 남긴다 `[데이터 공백]`.
- `monthly_volume`은 **오래된 달 → 최신 달** 순으로 관측됐다. 그래도 스크립트는 배열 순서를
  가정하지 않고 `month` 값의 최댓값을 기준월로 쓴다.
- `intents`는 0/1 플래그다(분수 아님). 두 플래그가 동시에 1일 수 있다.

### `trend_finder` 사용 규칙 (2026-09-29)

- 엔드포인트 `trend_finder/issue_list` · `keyword`는 **단일 시드**(배열 아님) · `period_days` 1~365(기본 14) · `limit`으로 출력 과금을 통제한다 — **기본값이 1,000(최대 10,000)이라 빠뜨리면 호출당 상한이 2,050이 된다. 항상 지정한다.**
- 예산 상한은 호출마다 `50 + 2 × limit`로 잡는다. 빈 결과 호출은 과금되지 않았다(input_count 0 · total_cost 0 · 2026-09-29 실측 1건) — 실소비는 `cost_detail`로 기록한다.
- 띄어쓴 여러 단어 시드는 단어 중 하나만 맞아도 이슈를 가져온다(실측: «캠핑 의자» 반환 50건 중 의자 관련 1건 · 캠핑장·차박·방송 사건 등 범위 밖 39건을 거르면 11건). 띄어쓰기 유무로 결과가 크게 달라진다 — 범위 밖 이슈를 거른 뒤의 건수로 판단한다.
- 일별 이슈 인덱스(구글 자동완성·검색결과 기반)를 검색한다. **실시간 크롤이 아니다.** 빈 결과는 «그 기간 매칭 없음»이라는 실측이다 — 기간을 넓혀 한 번 더 본 뒤 결론을 내리고, 이슈를 지어내지 않는다.
- 응답의 `summary`는 AI 생성 요약이다 — 인용할 때는 `[추정]`으로 적고 `source_links` 원문으로 확인한 문장만 `[실제 데이터]`로 올린다.
- 이슈는 **검색량이 아니다.** 검색량·추세 판정은 `keyword_info`로 한다. 최근 이슈는 월 그레인 지연 때문에 검색량에 아직 안 보일 수 있다 — «이슈 신호만 · 검색량 미확인»으로 따로 적는다.
- 인덱스가 구글 기반이라 네이버 비중이 큰 시장에서는 «국내 이슈 전체»로 단정하지 않는다.

### 크레딧 용어

- 호출 1건의 비용 = 응답 `cost_detail.total_cost`
- 계정 사용량 API(`/usage/summary`)는 **계정 전체 집계**다. 다른 세션·파이프라인의 소비가
  섞이므로 **개별 분석의 소진량으로 쓸 수 없다.** 리포트의 "이번 분석 소진"은 `cost_detail` 합산.
- `used_credits`는 **월간 누적 사용량**이지 잔여량이 아니다.

## 2. 필드 집계 창 (실측 검증)

`monthly_volume` 48개월 역산으로 검증한 결과다.

| 필드 | 실제 의미 | 판정 |
|---|---|---|
| `volume_avg` | **최신 3개월 평균** | ✅ 검증됨 |
| `volume_total` | **최신 12개월 합** — 끝은 조회일이 아니라 데이터 기준월 | ✅ 검증됨 |
| `monthly_volume` | 최장 48개월. 최신 월이 조회일보다 **이르다** — 2026-09-28 조회에서 1개월(기준월 2026-08)이었다. 고정값으로 쓰지 말고 **응답에서 읽는다** | ⚠️ 매번 확인 |
| `volume_trend` | 30개 집계 창 전수 대조에서 **일치하는 식 없음** | ❌ **판정 근거 금지** |
| `cpc` · `competition` | 광고 지표 | ✅ |
| `gg_*` · `nv_*` | 구글/네이버 분해 | ✅ |
| `demography` | 일부 국가만 반환 — 공백이 아니라 **사양** | ⚠️ |

### `monthly_volume` 행 스키마는 균일하지 않다

```json
{"month": "2026-07", "gg": 8100, "nv": 14710, "total": 22810}   // 정상
{"month": "2023-04", "gg": 40, "nv_code": 1}                     // nv·total 없음
{"month": "2023-05", "nv_code": 1}                               // gg조차 없음
```

`nv_code: 1` = 해당 월 네이버 볼륨 미제공. **`total` 키 자체가 없다.**
`row.get("total", 0)`으로 합산하면 조용히 과소집계된다 — 결측으로 세고, 비교 창에 결측이
있으면 그 키워드는 «계산 불가»로 남긴다.

## 3. 데이터 함정 8종 (처리 의무)

산출물이 정상적으로 완성되면서 **결론만 틀리는** 종류다. LM 데이터를 쓰는 스킬은
해당되는 항목을 반드시 처리한다.

| # | 함정 | 처리 |
|---|---|---|
| 1 | **조회일 ≠ 데이터 시점** (지연은 응답에서 읽는다 — 관측 1개월) | `monthly_volume` 최신 월을 읽어 `기준월 / 조회일 / 지연` 3종을 산출물 헤더에 표기 |
| 2 | **마지막 달 미완결** — 아직 채워지는 중 | 최신 월 MoM을 전년 같은 구간과 대조. 이번 달이 실제로 하락 + 낙폭이 30%p 이상 나쁘면 의심 → 제외하거나 재조회로 고정 확인 |
| 3 | **`volume_trend` 신뢰 불가** | `monthly_volume` 전년 동기 비교로 대체. 필드는 참고 컬럼으로만 보존 |
| 4 | **기저 0 성장률 폭발** | 최소 볼륨 게이트(전년 동기 기준) 통과분만 랭킹 |
| 5 | **표기변형 이중 계상** — 요청하지 않은 변형이 함께 반환됨 | `canonical` 그룹키로 묶고 집계는 그룹 기준. 행은 보존. ① **시계열이 완전히 같은 행은 같은 검색의 중복**으로 보고 한 번만 센다 — canonical이 달라도(어순·복수형·동의어) 적용한다. 시계열이 없으면 볼륨·CPC·경쟁도가 모두 같고 토큰이 겹칠 때만(`series_dedup.py`). ② 그 밖의 표기변형 그룹은 **하한(그룹 내 최댓값)과 상한(그룹 내 합)을 병기**한다. 순위·판정은 하한 기준으로 하되 상한과 뒤집히면 그 사실을 적는다. 둘 다 `[추정]`. 근거(2026-09-28): 미국 3개 카테고리에서 동일 시계열 묶음이 여분 볼륨의 최대 33.5% · 한국은 대조한 띄어쓰기 중복 쌍의 값이 같았고 어순 변형은 대부분 다른 검색이었다. 다른 카테고리·시장에서 재확인이 필요하다 |
| 6 | **결측 월 0 합산** | §2 규칙대로 결측 처리 |
| 7 | **절단을 수렴으로 오독** — `limit`에 붙은 라운드 | 라운드별 `요청 limit` vs `반환 수` 기록. 절단이면 수렴 판정 보류 |
| 8 | **브랜드가 지표를 부풀림** | 점유·기회·여지를 논하면 **논브랜드 분리** 산출 |

**실측 근거** (map-your-market v1.0→v1.3 감사, 3개 카테고리):
`volume_trend` 부호 불일치 38.1% / 36.4% / 74.7% · 마지막 달 하루 사이 +143% 정정 ·
커버리지 분모 붕괴 3/3 · 절단 상태 도달 판정 3/3.

## 4. 4-Label 표현 규율

| 라벨 | 정의 |
|---|---|
| `[실제 데이터]` | API 직접 반환값 |
| `[추정]` | 규칙·AI 해석, 복수 API 결합 |
| `[가정]` | 전제가 필요한 판단 (임계값·정규화 규칙·게이트) |
| `[데이터 공백]` | 미반환·임계 이하·결측 |

라벨 누락은 거부 사유다. 수치를 인용하는 모든 문장이 넷 중 하나에 속해야 한다.

## 5. 해석 한계 (모든 산출물에 적용)

- **월 그레인 · 1개월 이상 지연**(응답에서 읽는다) — 주간 조기경보에 쓸 수 없다
- 검색은 구매·사용이 아니라 **관심 신호**다. 점유율은 "검색량 기준 근사"로 표기
- 검색량 단위는 **건**이며 사람 수가 아니다 (한 사람이 여러 번 검색한다)
- 세션 인접(`path_finder`)은 집계 행동이지 개인 여정이 아니다
- 정책·시즌 임팩트는 **인과 단정 없이** 상관·동향으로 서술

## 6. 보안

- API 키는 파일·환경변수로만 보관한다. **리포트·로그·커밋·산출물에 절대 포함하지 않는다.**
- 저장소를 공개한다면 키 파일 경로를 `.gitignore`에 넣는다.
- 응답 원본(`raw/`)을 보존할 때도 요청 헤더는 저장하지 않는다.
