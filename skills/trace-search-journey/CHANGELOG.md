# trace-search-journey — 변경 이력

판 번호의 정본은 SKILL.md frontmatter `metadata.version` 이다. 새 판을 낼 때 두 곳을 같이 고친다.
결함은 무엇이 어떻게 틀렸고 어떻게 고쳤는지, 재발을 막는 검사와 함께 적는다 — 실데이터 실행에서 관측한 수치(검색량 · 건수 · 비율 · 순위)는 적지 않는다.

## v0.3.2 (2026-11-23 · lm-skills 1.8.0)

- 계약 v1.3 사본 — `ads_info` 금지를 풀었다. 시계열만 필요하면 `ads_info`를 쓸 수 있고, 단가는 첫 호출 `cost_detail`로 확인한다(명세 1/키워드 · 운영 환경에서도 1로 확인).
- 공개 전 정리: 실데이터 실행에서 관측한 수치 기록(검색량 · 건수 · 비율 · 순위 · 실행 날짜)을 걷어냈다 — 규칙 · 결함 서술 · 합성 픽스처는 그대로다.

## v0.3.0 (2026-09-30 · lm-skills 1.7.0)

선크림 KR 예시 실행(파일럿 `선크림` · 본 호출 `선스틱`) 결함 수정.
저장 응답으로 0크레딧 재실행 확인.

- **시드 표기 변경 검사** — path_finder가 `선크림`을 파일럿 경로 전부 `썬크림`으로 돌려줬다. `썬→선` 규칙이 없으면
  시드가 한 경로에서도 발견되지 않고 선크림 인접이 전부 `off_seed`로 조용히 집계됐다. `journey_paths.py`는 시드가 0경로이고 한 글자
  다른 표기가 사용 경로 절반 이상에 있으면 종료 코드 3으로 멈추고 규칙 `{"썬": "선"}`을 제안한다(`--allow-seed-variant`로만
  진행). 일부 경로만이면 요약 경고. `path_budget.py`도 파일럿 응답에서 같은 경고를 낸다. STEP 3에 path_finder 표기 변경 명시
- **시드 고정** — `path_budget.py --seeds a,b [--seeds-only]`. 사용자가 `선스틱`을 지정했는데 볼륨 순으로 `선크림 추천`
  이 `call`로 잡혔다. 지정 시드가 볼륨 순보다 먼저 예산을 받고, 게이트·예산은 그대로 적용하며 보류되면 note에
  이유를 적는다. 지정 밖 후보는 `hold_not_selected`, 응답에 없는 지정 시드는 `hold_not_in_metrics`
- **파일럿 설계** — 주 시드 `선크림`이 파일럿 limit으로 끝나 `선스틱`(본 limit)과 limit이 어긋났다. 파일럿은 사용자가 정한
  시드가 아닌 후보로 돌리는 것을 우선하고, 주 시드일 수밖에 없으면 `--recall-pilot`으로 본 limit 재호출을 예산 안에서
  계획한다. 재호출하지 않으면 «limit 맞추기» 추가 비용을 출력한다(이 실행에서는 재호출 계획이 남은 계획 예산을 넘었다)
- **공통 줄기 통계** — 반환 경로 일부가 앞 3걸음을 공유하고 끝만 갈라졌다. 전이 CSV에
  `stem_count`, 노드 CSV에 `stems_with_keyword`, 요약에 시드별 서로 다른 줄기 수·가장 큰 줄기·
  경고, 시드 다음/앞 검색 표에 «서로 다른 줄기» 열을 추가(`--stem-len`, 기본 3 [가정]). 예: `선스틱 → 선스틱 선크림 차이`는
  path_count가 커도 stem_count 1. 기존 10개 컬럼 값은 바뀌지 않는다(저장 run 재집계로 동일 확인)
- **좁힌 계획의 보류 후보** — 후보를 지운 metrics로 계획을 다시 세워 요약의 보류 후보가 «없음»으로 나왔다(전체 계획에는
  보류·제외 후보가 있었다). `journey_paths.py --plan-full`이 좁힌 계획에서 빠진 후보를 `excluded_from_plan (전체 계획: …)`으로
  싣고, 좁힌 계획만 주면 «없음» 대신 «빠진 후보는 보이지 않는다»고 적는다
- **r 관측치 추가** — 파일럿 r보다 본 호출 r이 작아 계획이 크게 과대였다. SKILL.md 예산 절과
  `path_budget.py` 출력에 과소·과대 사례를 함께 적었다
- `selftest.py`에 위 1·2·3·4·5 회귀 추가(이전 스크립트로 돌리면 17건 실패 확인)
