### v1.1 (2026-09-28) — 계약 T5 개정 반영

표기변형 그룹 볼륨을 «최댓값 하나만» 세던 것을 **하한(최댓값)·상한(합) 병기**로 바꿨다. `volume_12m`·
`volume_share_in_axis`·`yoy_coverage`를 `_lo`·`_hi`로 나누고, 키워드 CSV에 `group_volume_lo`·`group_volume_hi`·
`label_group_volume`, 항목 CSV에 `axis_rank_hi`·`trend_call_hi`·`flip_under_hi`·`yoy_series_basis`를 더했다.
순위·판정은 하한 기준이고 상한에서 뒤집히면 표시한다. 추세는 대표 검색어(하한 기준)로만 낸다.

### v1.0 (2026-09-28) — 카탈로그 카드 재생성

원본 카드(«find-what-customers-actually-want»)에서 **바꾼 것과 이유**:

| 원본 | 조치 | 이유 |
|---|---|---|
| LLM 분류 + «분류 임계값 0.7» · `axis_confidence` 컬럼 | **정규식 축 사전**으로 교체, 신뢰도 점수 삭제 | 임계값을 산출하는 규칙이 없어 재현·검증 불가. 같은 입력에 다른 분류가 나온다 |
| `Priority = log(volume) × growth_3m × (1+cpc) × cluster_size_weight` | **검색량 순위 + 추세 옆 열**로 교체 | `growth_3m` 정의 부재(`volume_trend`면 계약상 판정 금지) · 음수 성장이 곱셈으로 순위를 뒤집음 · 가중치 근거 없음 |
| `cluster_finder` 1회 (군집 크기 가중치) | **삭제** | 3축 분류에 불필요. 단일 호출이 결정식상 6,150(limit 120) |
| 크레딧 «5,500~6,800» | **결정식**으로 교체 · 2단 조회 | 관측 범위는 상한이 아니다 |
| `cpc`를 «간접 수요 신호»로 점수에 반영 | 참고 컬럼으로만 보존 | 광고 경쟁은 니즈 크기와 다른 양이다 |
| «PM 로드맵 우선순위를 결정» | «검토 후보»로 표현 수위 조정 | 검색은 관심 신호다 |
| 예시 `brand-a cordless …` 가공 수치 | 공개 카테고리(전동칫솔 KR) 사전 예시로 교체, 가공 수치 삭제 | 익명 예시는 좋은 입력을 가르치지 못하고, 가공 수치는 실측으로 오독된다 |
| 추세 · 기준월 · 결측 · 절단 · 표기변형 · 브랜드 처리 없음 | 함정 T1~T8 처리 추가 | 데이터 계약 §3 |

유지한 것: 3축 정의(Feature/Attribute/Pain) · 불편 표지어(부정·고장 표현) 인식 · `intent_finder` 확장 ·
B2B·신생 카테고리 한계 경고 · 4-Label.
