# compare-markets-across-countries — 변경 이력

판 번호의 정본은 SKILL.md frontmatter `metadata.version` 이다. 새 판을 낼 때 두 곳을 같이 고친다.
결함은 무엇이 어떻게 틀렸고 어떻게 고쳤는지, 재발을 막는 검사와 함께 적는다 — 실데이터 실행에서 관측한 수치(검색량 · 건수 · 비율 · 순위)는 적지 않는다.

| 결함 | 조치 | 근거 (저장 응답 재계산) |

| P0 `Master.index`가 기준어는 같은 canonical의 **마지막** 원문, 개념은 **첫** 원문을 2단 요청어로 골라 1단 응답에 없던 표기가 2단 요청어가 됨 | 기준어·개념 모두 «먼저 적은 원문» 규칙으로 통일(`raw_terms`·`originals`). `select`는 같은 canonical 원문 중 **1단 응답에 실제로 있는** 첫 원문을 고른다 | 2단 요청어 kr «썬크림» → «선크림», jp «日やけ止め»(1단 응답에 없음) → «日焼け止め» |
